# Our Dasar

Our Dasar is a life-move planning app for checking whether real-life expenses can handle a major decision, such as buying a home, renting or moving, buying a car, or having/adopting a child.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

This project is set up for GitHub Pages through GitHub Actions. After pushing to `main`, the workflow in `.github/workflows/pages.yml` builds the app and deploys the `dist/` folder.

In the GitHub repository settings, set **Pages** to deploy from **GitHub Actions**.
